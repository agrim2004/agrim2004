### 💰 Expense Tracker 

📌 A full-stack expense management application that helps users track daily spending, organize transactions, and monitor expenses through a clean, responsive interface.

- 💸 Add, view, and delete expense records.
- 🗂️ Organize expenses by category with search and date-range filters.
- 💱 Convert currencies using an external API.
- 📊 View expense summaries to better understand spending.
- ⚙️ Manage data through RESTful APIs built with Node.js and Express.js.
- 🗄️ Store and retrieve expense data using MongoDB.

**Tech Stack:** React.js • Vite • Node.js • Express.js • MongoDB • REST APIs • JavaScript • CSS3

🌐 [Live Demo](https://expense-tracker-updated-lemon.vercel.app/)
